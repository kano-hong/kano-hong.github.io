## 問題

AI 寫程式很快，但它也會很有自信地做錯事。實際遇過的有：

- **把機密印進對話。** 想用 `grep -v password` 過濾，結果另一種寫法的「密碼」漏了出來；想看容器的環境變數，結果一整行設定 JSON 連同帳密一起印出。
- **批次刪錯東西。** 用過濾結果批次刪容器，過濾條件沒生效，刪到不該刪的。
- **每次都從頭查。** 同一套換版或排查流程，每個 session 都要重新摸索一次，也每次都可能漏掉同一個步驟。

所以我的重點放在三件事：讓它出不了大錯、讓做過的事可以重複、讓它能直接操作真正的工具。

## 決策 1：用 hook 擋下事故的寫法

Claude Code 每次執行指令前，都會先經過我寫的一個 hook（`PreToolUse`）。規則不是憑空想的，每一條都對應一次真實事故：

- **印出機密檔**：`.env`、`*.pem` 這類檔案直接印出來就擋；只數筆數、只印 key、存進變數不印出就放行。
- **印出整份環境變數**：容器的 env、`/proc/*/environ` 擋；交給 python 只取 key 就放行。
- **用過濾結果批次刪容器**：一律擋，要求改用明確的名稱。
- **會刪資料的清理**：`compose down -v`、`docker system prune` 不直接擋，改成先問我。

被擋下時，訊息會直接寫出安全的寫法，所以 AI 下一步通常就會改寫，而不是換個寫法繞過去。

規則改完要驗證兩件事：49 條測試全過，再把 Claude Code 對話紀錄裡 14,693 條真實指令全部重播一次，結果擋下 82 條、詢問 34 條，0.74 秒跑完。重播是為了確認不會誤擋日常的指令，太吵的護欄最後只會被關掉。

## 決策 2：把維運流程寫成 skill

只要一件事做過第二次，我就把它寫成 skill：一份給 AI 看的作業說明，加上它要用的腳本。下次只要說「上 Prod」或「全部打包一次」，它就照同一套步驟做，而且步驟裡寫著當初為什麼要這樣做。

- **Prod 換版**：本機打包、正式機斷網建映像、比對有效設定、先換 1 台再換其餘 7 台、1 小時複查（見〈[真錢遊戲的 Prod 換版](../prod-canary-release/)〉）。
- **全遊戲建置**：限流觸發三條產品線的每款遊戲，失敗依類型分類。
- **部署文件同步**：部署狀態一有變化，就把文件更新並推上去。
- **唯讀查詢**：查正式環境的注單、讀 Lark 告警群的報錯，全部只讀不寫。
- **實機除錯**：用指令操作 USB 接著的 iPhone Safari，量測真機上的畫面與記憶體。

調 skill 的觸發描述時也踩到一個坑：評測工具會用完整權限跑測試句，像「上 Prod」這種句子，評測時就可能真的連上正式機。所以我把評測子程序限制成只能讀檔和呼叫 skill。

## 決策 3：讓 AI 直接操作編輯器

Cocos Creator 是桌面程式，AI 原本碰不到裡面的場景和 prefab，只能請人點。

**cocos-mcp** 是我做的開源專案：一個跑在 Cocos Creator 編輯器行程裡的 MCP server，讓 AI 可以查詢即時的場景樹、讀寫資產、啟動建置、讀 log，並截圖確認自己剛剛做了什麼。

其他 Cocos MCP server 動輒 100 多個工具，再加上「工具組合」把大部分藏起來。我只做 11 個工具：幾個通用工具，加上一個能讀編輯器自己 TypeScript 型別定義的工具。AI 先查到函式簽名，再用通用的 `editor_request` 呼叫。零依賴、不用建置，專案根目錄一份 `.mcp.json` 同時給兩端讀，設定就不會不同步。寫入屬性的工具會立刻讀回、回報改前與改後的值，讓「成功了」是量出來的，而不是工具自己說的。

## 決策 4：平行 agent 要控制額度

寫 46 份規格書時，我一次開了兩個工作流、共 106 個 agent 平行跑，一小時就撞到額度上限，50 多個 agent 一起失敗。額度是整個 session 共用的滾動視窗，撞到時不是變慢，而是整批失敗。

改成一次只跑一個工作流、每批約 30 個 agent 之後，連續 5 批零失敗。另一個教訓是：被標成失敗的 agent，不代表它的副作用沒發生，很多是檔案寫完了才在回報時失敗，重試前要先看磁碟。

## 決策 5：給機器人的護欄

- **Lark 上的 AI 機器人**：有人在告警群問它問題，它只讀得到 Mac 上的靜態檔，卻很有把握地指向錯的容器。我替它加上硬規則「看不到不等於沒發生」，再給它一個唯讀、不收參數的工具，讀告警群最近的機器人訊息。
- **讓機器人查正式機**：給它一把專用金鑰，只能執行固定的唯讀指令（forced command）；重啟這類動作要經過核准卡片，有人按了才會送出。群組訊息是不可信的輸入，所以不給它任意指令。
- **團隊共用**：替專案加上給 AI agent 看的 `AGENTS.md`，把 hook、skill、subagent 放進版控讓團隊共用；我自己的 CLAUDE.md 也從 11.9 萬字元整理到約 3 萬，runbook 都搬進 skill。

## 學到的事

- **護欄要從事故來。** 憑空想的規則不是太鬆就是太吵；每條規則都對應一次真實事故，再用歷史指令確認不會誤擋。
- **AI 很有自信的時候最要驗證。** 它說「是這個容器」，要看它到底讀到了什麼；它說「修好了」，要問是在哪個環境驗證的。
- **檔案層的修改有時比走工具好。** 同一個 prefab 修改，直接改檔案是 +35／−0 行，透過編輯器重新序列化是 +2340／−1957 行，review 的人根本看不出改了什麼。
